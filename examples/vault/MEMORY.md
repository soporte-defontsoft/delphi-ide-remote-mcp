# MEMORY

The index of this vault. One line per note: link, then **what the note is for**
— written so a reader can decide whether to open it without opening it.

Curated by a human. Agents ask for a line to be added; they do not add it.

## How to write a good index line

- Say what question the note answers, not what it is named.
  Good: "why the importer runs nightly instead of on demand".
  Useless: "importer notes".
- Keep one line. If it needs two, the note is doing too much — split it.
- Sort by usefulness, not alphabetically. The lines people need most go first.
