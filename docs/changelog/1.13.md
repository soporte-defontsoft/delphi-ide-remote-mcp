# Changelog: the 1.13 line

The entries of the 1.13 line, moved here whole from [CHANGELOG.md](../../CHANGELOG.md): nothing was cut or reworded.

## [1.13.1] - 2026-10-05

What the night reports from the 13.2 machine ran into: answers that did not
say whose fix it was, or what the agent could do instead.

### Changed

- A root or reference whose drive letter is not connected on the server is
  refused by the gate of every call with `WS-022 DENIED`, which names the
  root, says the drive is not connected and that it is the operator's to
  fix, and lists the roots that are there. It was a `Directory not found`
  (`WS-008`) in each tool, read as a typo - and a write there ended as an
  internal error (`SYS-009`, "The drive cannot be found"). Nothing is opened
  to decide it: the process's own drive table.
- `delphi_workspace` lists the roots it cannot reach right now
  (`unavailableRoots`, each with its reason: a drive letter not connected, a
  local root folder that does not exist).
- `delphi_projects` without `root` skips a configured root that is not there
  and names it (`PROJ-005`); the first missing root used to fail the whole
  list (`PROJ-003`). With an explicit `root` that does not exist it is still
  `PROJ-003`.
- `delphi_fetch` answers with the download link only above 1 MB (it was
  4 MB): a 1.37 MB zip came back as 3.6 million characters of base64 inside
  the answer. `maxbytes<=1048576` still asks for inline chunks.
- Git's "detected dubious ownership" (a repository on a network share or a
  NAS, owned by another account) carries `GIT-057`: the fix is the
  operator's, `safe.directory` in the global Git configuration of the
  server's account, which no tool writes. The hints drawn from what Git said
  now go with every `GIT-036`, also when the refusal comes from the
  repository jail before the command.

### Fixed

- The note on mentions (`LSP-015`) and the description of
  `delphi_references` said that a name inside a string never blocks a
  rename; it does (`RENAME-020`), because it may be a `FindComponent` or RTTI
  by name. A comment does not.
- `WS-020` (`delphi_package`) promised a download link for "big zips" without
  saying from what size; it says 1 MB now, like `delphi_fetch`.
- `region` and `window` of a capture say upfront that they do not combine.

### Internal

- `tests/test_paredes_1131.py`: each wall above, each fix with its mutant
  red; a dubious-ownership repository is reproduced with
  `GIT_TEST_ASSUME_DIFFERENT_OWNER` and the machine's Git configuration
  isolated.
- `letras_libres` lives once, in `tests/mcp_cliente.py` (it was copied in two
  batteries).

## [1.13.0] - 2026-10-04

One reader where there were several - Pascal classes, the citation of a
line, an agent's regular expression -, a jail that closes what two rounds of
review measured, one of them a write outside the workspace through a Git
submodule, and the field reports of the day.

### Added

- `delphi_git ls-remote`: the refs of a remote, read-only (`--heads`,
  `--tags`, `--refs`, `--symref`, `--exit-code`), with the same remote policy
  as fetch and pull, and allowed to a read-only credential.
- `delphi_search` and `vault_search` with `regex=true` go to PCRE directly; a
  pattern the engine gives up on says so (`SEARCH-005`). Hits come grouped by
  file, and a file over 8 MB is named instead of read.
- Read-only `delphi_git` answers are paged by lines with `offset` instead of
  cut; branch and tag listings take it, the commands that write refuse it
  (`GIT-056`), and a line longer than a page is reported (`GIT-055`).
- `delphi_designer tree` takes `maxdepth`.
- `[Server] MaxEngines`: a cap on warm LSP engines, the least recently used
  goes first (0, the default, is no cap).

### Changed

- **One reader for Pascal classes** (`Lsp.PascalDecl`, on the token reader):
  where a type starts and ends, its sections, fields and routines, class
  helpers, generic parameters by name, `class var`, both branches of an
  `{$IFDEF}`. `insert=metodo`, `check-binding`, `delphi_references`,
  `add-unit` and the folder digest use it, with one ancestor walk. A method of
  a generic class is qualified as `TCaja<T>.Foo` (`TCaja.Foo` does not
  compile); an interposer ancestor (`class(UBase.TBaseForm)`) is no longer
  taken for a cycle; an asm label such as `@@END` no longer closes a block.
- **One lexicon for identifiers**, measured against dcc (any non-ASCII BMP
  letter, Unicode case folding), and for routine keywords and directives.
- **One composer for the `N|text` citation.** The outbound masker lets
  through only the citations composed in that call; JSON and markdown answers
  keep their content fields verbatim and mask the rest, object keys included.
- `delphi_designer get` and `delphi_styles get` number each line like
  `delphi_read` and leave it unmasked: a path in a property value came out as
  `srvd:` and an anchor copied from it did not match the disk.
- With both IDEs installed, the designer tables are read for Win32, the IDE in
  normal use; Win64 only when the 64-bit IDE is the only one. The tables go to
  generation 6.
- `delphi_docs search` takes a signature by its name and drops generic
  arguments: `FormatDateTime(const Format: string; ...)` and `TList<T>.Add`
  answered `DOCS-006` (Hermes, field data).
- `delphi_search` refuses a query with a line break (`SEARCH-008`): the search
  is line by line, and the conventions say one characteristic line per search.
- `delphi_desktop` refused because the desktop node is not in
  `RemoteRunProjects` now answers `RUN-020`, its own message: the node is this
  server's own binary, and what the operator grants by listing `McpDesktopNode`
  (or `all`) is seeing and typing on that desktop. It answered the `RUN-007` of
  an agent's project, which did not say so (Hermes, field report). The tool
  description names the three switches it needs, and the README,
  `settings.example.ini` and `CAPABILITIES.json` say it too: until now only the
  skill did. `RUN-007` says that only the operator extends that list.
- Leaner answers and `tools/list` (105,592 -> 98,833 characters): short sibling
  descriptions, no fixed notes in build and test, `audit=clean` instead of six
  counters, thinner symbol trees, a folder digest capped by size that names
  what it leaves out (`LSP-034`).
- `BUILD-042` proposes folders of the workspace, through the read gate.

### Fixed

- **A push wrote outside the workspace through a submodule.** With
  `push.recurseSubmodules=on-demand` in `.git/config` - which an agent can
  write - `delphi_git push` pushed a submodule commit to the submodule's own
  remote, outside every root (measured; 1.12.1 did it too). Git never recurses
  into submodules now: the common command composer sets
  `submodule.recurse=false` for every command and `--no-recurse-submodules`
  for fetch, pull and push, whatever the repository, global or per-submodule
  configuration says; each defense blocks on its own (measured with Git 2.53).
  Fetch and pull reached a submodule's remote the same way.
- A `.git` FILE whose gitdir points outside the workspace is refused with
  `GIT-041`, `init` over an existing `.git` included: `init --shared=group`
  wrote outside (measured).
- **Names behind a junction.** `delphi_test discover`, the folder digest of
  `delphi_symbols`, `delphi_references`, `delphi_rename_symbol` and the purge
  of the trash walked trees with the RTL and named files behind a junction
  that leads outside the roots. They share one walker that follows a link
  only when what is behind it may be read (`WalkFiles`, `Lsp.Guard`).
- A control character in a path (`U+0000..U+001F`) is refused before anything
  else (`GUARD-032`), without repeating the path: a NUL truncated the name in
  Win32 and `delphi_list` answered an empty, valid result.
- `ReadOnlyPaths` protects what hangs from it by the same location rule as the
  rest of the jail, equally with long names and 8.3 aliases; an entry that
  contains a root that is a junction protects that root and gets no false
  "outside" warning. The 1.9.1 note below said the opposite: that measurement
  ran with a TEMP path that had an 8.3 component.
- Git keeps a root declared through a junction, also with an 8.3 target, and
  a relative remote from a subfolder of a bare repository is resolved from the
  folder Git uses: both were refused (`GIT-041`, `GIT-044`).
- `delphi_references` in generic and nested families: `THija<T>.Pinta` and
  `TOuter.TInner.Pinta` gave no class, and the call to an override in a
  generic family was rejected as a homonym.
- `delphi_definition kind=declaration` asked another engine for a unit shared
  by two projects (and reported a false `LSP-021`), and `delphi_references`
  warmed a candidate in another project's engine: both ask the engine that is
  answering.
- A `.delphilsp.json` that is not a JSON object answered `SYS-006` in every
  tool of its engine; an IDE settings file written after the first question
  was never taken.
- The echo of a batch that removes the last line of a file quoted the empty
  tail (`3|`); it says `(line 3 removed)`.
- The SDK card skips a field that is not text instead of failing the profile
  list.

### Internal

- New batteries: `test_lector_clases`, `test_ronda16_menores`,
  `test_git_jaula_113`, `test_ruta_controles`, `test_jaula_recorridos`,
  `test_jaula_lectores_guardas`, `test_readonly_rutas_83`; 266 unit tests.
  Every fix has a test that its mutant turns red. The jail work was done by
  Codex and reviewed by Claude.
- One reader of a JSON that must be an object (`ObjetoJson`, `Lsp.Json`).
- `Declared(TBytes)` is false without `System.SysUtils` (measured with dcc).
- Jail batteries remove their scratch folders, exe copies included; two
  batteries stop writing `AllowDesktopControl`, a key gone since 1.0.16.
- Measured and not reproduced, so no change: a warning parser for
  `git remote` (no real warning could be produced); the "two millisecond
  windows" of a transient `FILE-036`. Guarded but not measured from inside:
  which `.dproj` `FindDproj` selects for a loose unit behind a junction.
